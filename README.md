# 📌 TMBD React Movie Search

### This project is a movie search application built with React and Vite that demonstrates working with server data using TanStack Query (React Query).

The app fetches movies from the TMDB API, supports search and pagination, and efficiently manages loading, error, and caching states. Data requests are handled with Axios, and pagination is implemented using React Paginate.
The project follows a modular component structure, uses TypeScript for type safety, and CSS Modules for styling.

## 🛠 Technologies

- React — UI development
- Vite — Build tool and dev server
- TypeScript — Type safety
- TanStack Query — Server state management
- Axios — HTTP requests
- React Paginate — Pagination
- CSS Modules — Styling
- Prettier — Code formatting
- modern-normalize — Cross-browser consistency

## 🎯 Purpose
## This project was created to practice working with APIs, pagination, and server-state management in React using TanStack Query.
